# Zoo World

Прототип зоопарка на **Unity 6000.3.18f1**: случайное движение животных, прыжки и рывки, физические столкновения, пищевая цепочка и счётчики смертей через uGUI.

Виды и правила задаются JSON-конфигами. Prefab и конфиги можно загружать во время игры через **Remote Addressables**. Используются композиция поведения, UniTask с отменой задач и пул запасной геометрии. ECS не используется.

## Локальная проверка Remote Addressables

Понадобятся **Windows**, Unity с поддержкой **StandaloneWindows64**, Git и Python 3.

1. Откройте проект в Unity и дождитесь импорта пакетов и завершения компиляции.
2. Откройте сцену `Assets/Zoo/Scenes/Zoo.unity` и выберите платформу **Windows / StandaloneWindows64**.
3. Вне Play Mode выполните **Zoo → Content → Build CDN release-2**. Сборщик подготовит каталог, bundles и JSON-конфиги в соседней с проектом папке `cdn_server`, а также выберет режим **Use Existing Build**.
4. Из корня проекта запустите сервер и оставьте его работать:

   ```powershell
   & ".\Tools\LocalCdn\start_local_cdn.cmd"
   ```

   Требуется свободный порт **8080**. Если Python не найден, задайте `$env:CDN_PYTHON = "C:\Path\To\python.exe"` и повторите запуск. Остановка сервера — **Ctrl+C**.

5. Проверьте, что открывается [манифест release-2](http://127.0.0.1:8080/release-2/release.json).
6. В **Window → Asset Management → Addressables → Groups** убедитесь, что **Play Mode Script → Use Existing Build**. Режим **Use Asset Database** не проверяет скачивание bundles с сервера.
7. На объекте **Zoo**, компонент **ZooBootstrap**, до запуска игры проверьте **Release Manifest Url**:

   ```text
   http://127.0.0.1:8080/release-2/release.json
   ```

8. Нажмите **Play**. Стартовая версия — `Active: prototype-1`: появляются лягушки и змеи.
9. **Не останавливая игру**, нажмите **Update content**. Дождитесь `Active: release-2`.
10. Через 1–2 секунды начнут появляться прыгающие каракалы. Существующие животные сохранятся: в демонстрационном выпуске только новые спавны переключаются на каракала.

**Reload JSON после обновления нажимать не нужно:** эта кнопка возвращает локальный конфиг `prototype-1`.

В окне сервера видны HTTP-запросы. При повторной проверке bundles могут загружаться из кэша Unity. При ошибке обновления текущая конфигурация сохраняется; причину смотрите в статусе игры и Console.

Сборщик настроен на демонстрационный `release-2` для Windows64. Собранные файлы CDN не включены в Git — после клонирования их нужно собрать шагом 3.
